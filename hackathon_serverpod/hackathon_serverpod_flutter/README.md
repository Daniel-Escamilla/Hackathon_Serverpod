# hackathon_serverpod_flutter

KarmaHome's Flutter app: Android and the web, talking to the Serverpod backend in
`../hackathon_serverpod_server`.

With the server running, from this directory:

    flutter run

How to point it at another server, run it on a phone, sign in with Google and run the tests is in
the [root README](../../README.md). How the code is laid out is in
[`../AGENTS.md`](../AGENTS.md#flutter-conventions), and the design standard in
[`docs/DESIGN.md`](../../docs/DESIGN.md).
