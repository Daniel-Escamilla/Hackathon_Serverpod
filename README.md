# Hackathon Serverpod

Full-stack app built with [Serverpod](https://serverpod.dev) (Dart backend) and Flutter, for the **Build Something Real** hackathon (builderbase.com), running 2026-09-15 to 2026-10-14.

## Stack

- Backend: Serverpod
- Frontend: Flutter / Dart
- Client generated via `serverpod generate`

## Getting started

```
serverpod create <project_name>
cd <project_name>/<project_name>_server
docker compose up --build --detach
dart bin/main.dart
```
